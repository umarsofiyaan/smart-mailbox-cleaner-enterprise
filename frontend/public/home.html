How Smart Mailbox Cleaner works

1

Connect your Gmail account

Sign in with Google OAuth. We request only the minimum Gmail API permissions: read metadata to find storage-heavy emails, and modify to move them to Trash. We request no access to email content or attachments.

2

Scan and categorise emails

Our scanner reads Gmail message metadata - size, date, labels - to group emails into actionable categories: large attachments (10MB+), old promotional emails (90+ days), social notifications, and expired calendar invites.

3

Clean with one click, undo anytime

Review each category and choose what to move to Trash. Every action is recorded. Use the Undo button in your dashboard to restore emails within 30 days. No emails are deleted without your explicit confirmation.

📋 Google API permissions we request

We follow the principle of minimal access - requesting only the Gmail API scopes strictly necessary to provide the service. You can revoke access at any time from Google Account Permissions.

gmail.readonly

Read Gmail message metadata (message size, date, labels) to identify emails consuming storage. We never read email body content.

gmail.modify

Move selected emails to Gmail Trash at your explicit request. Restore emails when you use the Undo feature. No permanent deletion.

drive.metadata.readonly

Read Google storage quota metadata (total/used) to show storage usage and estimated cleanup impact. No Drive file content is accessed.

Our use of Google API data complies with the Google API Services User Data Policy , including the Limited Use requirements. We do not transfer your Google user data to third parties except as necessary to operate the service, and we never use it to serve advertisements.
