How Smart Mailbox Cleaner works

1

Connect your Gmail account

Sign in with Google. We request only the minimum Gmail API permissions — read metadata and move to Trash. We never request access to email content.

2

Scan and categorise emails

We scan your Gmail metadata and group emails into categories: large attachments (10MB+), old promotions, social notifications, expired calendar invites, and more.

3

Clean with one click, undo anytime

Review the suggestions and move categories to Trash with one click. Changed your mind? Undo from your dashboard within 30 days — no questions asked.

📋 Google API Permissions we request

We request only the permissions necessary to provide the service. You can revoke our access at any time from Google Account Permissions.

gmail.readonly

Read email metadata (size, labels, dates) to find emails using storage. We never read email body content or attachments.

gmail.modify

Move selected emails to Gmail Trash at your explicit request, and restore them when you use the Undo feature.

No additional Gmail scopes

Smart Mailbox Cleaner only requests gmail.readonly and gmail.modify for Gmail data access.

Our use of Google API data follows the Google API Services User Data Policy, including Limited Use requirements. We do not sell or use your data for advertising.
